# QP12 更新说明（v1.0.8）

本次更新修复「订单生成 · 选择配件窗口」库存列偶发显示为 0 的问题。程序版本号升级为 1.0.8。

## 一、选择配件窗口库存显示修复

1. **库存偶发显示 0 的问题修复**：此前库存列按 1.5 秒实时查询，网络稍慢时本次查不到的配件会被"降级"显示为 0（实际有货）。现改为：超时后对本次没查到的配件自动用更长窗口（10 秒）补查一次，补到即显示真实库存；补查后仍查不到的才是真无库存。
2. **降级提示更准确**：只有当页面显示的确实不是最新值时，才提示"库存为缓存值"；补查成功、页面全部为实时值时不再误导性提示。
3. **新增诊断日志**：程序会记录库存检索的路径、耗时与异常明细（exe 同目录 debug.log），便于弱网环境下偶发问题的后续定位。

## 二、使用注意事项

1. 桌面端升级不会覆盖已有的数据库连接与打印配置。
2. 网络较慢时，检索后状态栏可能短暂出现"库存为缓存值"提示并稍作等待补查，属正常现象；补查期间请稍候再操作。
