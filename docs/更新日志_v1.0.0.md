# QP12 更新说明（v1.0.0）

本次更新主要修复 Web 端手机使用时的排版问题，并按现场反馈调整手机端配件卡片的显示内容。电脑端功能与操作无变化，可直接升级。程序版本号自本版起统一为 1.0.0。

## 一、Web 手机端排版修复

1. **字段标签错位修复**：配件库存列表、销售明细、单据查询列表在手机上以卡片显示，此前卡片上的字段名与实际内容错位（例如把内部编号标成"名称"、名称标成"车型"），已全部改正。
2. **库存恢复显示**：修复手机端配件卡片不显示库存的问题——手机开单时库存是必看信息。
3. **弹窗明细标签修复**：单据详情、销售历史、进货历史弹窗在手机上的字段名已按实际内容修正；此前进货历史与销售历史共用一套标签、进货表的字段名全部错位。
4. **电脑端表格同步修正**：配件列表"库存/零售价/批发价"的对齐与标红、"折后总额"的蓝色高亮恢复到正确列。电脑端表格的列与字段保持不变。
5. **其他适配**：小屏手机登录页不再溢出；错误提示较长时可正常换行显示，不再被截断。

## 二、手机配件卡片显示调整

按现场需求，手机端配件卡片改为三行显示，一行两个字段：

- 编码｜名称
- 车型｜库存
- 进价｜售价

口径说明：编码显示内部编号；进价为该配件当前批次的含税进价；售价为零售价。批发价、货位、仓库等字段在电脑端表格中继续保留。

## 三、使用注意事项

1. 本次仅涉及界面显示，不改动任何业务逻辑与数据，升级后无需调整数据。
2. 手机浏览器如仍显示旧样式，请刷新页面（或清除浏览器缓存）后再使用。
3. 桌面端程序版本号升级为 1.0.0，自动检查更新功能不受影响。
