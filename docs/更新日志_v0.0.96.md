# QP12 更新说明（v0.0.96）

本次更新围绕「Web 端在线使用」「进货历史随手可查」「数量录入更严谨」三方面改进，并修复了退出、长文本保存等若干问题。

## 一、新增与改进

### 1. Web 端在线开单与查询
- 工作台新增「Web 端服务」区域（仅系统管理员可见），可一键启动或停止。
- 启动后会显示局域网访问地址、运行时长和当前在线人数，同事用浏览器即可登录使用。
- 浏览器端支持销售开单、单据查询和整单确认（付款方式、发货方式、销售类型、客户信用参考）。
- Web 端打印直接调用运行桌面端电脑的默认打印机，票面与桌面端一致，不会弹出浏览器打印窗口。
- Web 端与桌面端使用同一套数据、同一套账号权限，并始终连接当前所选的数据库。

### 2. 进货历史随手可查
- 入库页和订单生成页新增「进货历史」区域：在上方明细中点选一个配件，右侧立即显示该配件的历史进货记录（单号、日期、供应商、数量、进价）。
- 无需再点查询按钮；快速连续切换配件时只显示最后一次的结果，不会出现串数据。
- 进货退货记录（数量为负）整行红字显示，进价参考一目了然。

### 3. 供应商管理更完整
- 新增和修改供应商改为同一个编辑窗口，可一次维护联系人、电话、税率、地址、备注等信息。
- 在入库页输入供应商名称后按回车：若系统中已有该供应商会自动带出编号；若没有会询问是否新增，确认后可直接建立并回填。
- 业务页的供应商搜索同时覆盖供应商档案和历史存量供应商，老客户供应商也能正常搜到。
- 入库保存前会校验供应商是否存在，名称对不上时不允许暂存或生效，避免产生无效单据。

### 4. 数量统一按整数处理
- 所有数量输入框只接受整数：输入小数点或粘贴带小数的内容时，本次输入整段还原并提示，不会悄悄改成别的数字。
- 订单生成、订货库管理、库存调仓、入库明细、入库退货、报价、最小包装数等场景均增加了整数校验。
- 列表中的数量列统一按整数显示（与原有习惯一致），打印票面和清单同步使用整数格式。

### 5. 界面与表格优化
- 全系统表格统一增加竖向网格线，表头分隔线与表格线颜色一致，查看数据更清晰。
- 选择配件窗口：库存为 0 的配件以红字提示；已订货的配件使用浅绿底色，与警戒红、警戒黄状态区分更明显。
- 订单生成页显示在途数量和公式建议订数，订货决策更直观。
- 入库明细列表精简为常用列；分类码、产地、单位、货位、仓库、备注等仍可在行编辑窗口中维护。
- 多个查询页和报表的数量列格式、列宽及顺序做了统一调整。

## 二、问题修复

- 修复退出软件时，确认后可能无法关闭或出现异常的问题；取消退出后可再次正常询问。
- 修复配件备注等长文本内容过长时保存失败、或内容被悄悄截短的问题；完整备注仍保留在配件属性中。
- 修复供应商维护时可能误操作到其它供应商记录的问题，供应商档案统一在管理页维护。
- 修复部分数量场景缺少校验、可能把小数写入单据的问题。

## 三、使用注意事项

1. Web 端服务仅系统管理员在工作台可见；启动后请把界面上显示的地址发给同事，需在同一局域网内访问。
2. Web 端打印使用运行桌面端那台电脑的默认打印机，请先确认该电脑已正确设置默认打印机。
3. 数量录入不再接受小数；历史数据中如存在小数，列表显示会按整数呈现，但原数据不会被自动修改。
4. 升级安装不会覆盖已有的数据库连接和打印配置；首次安装仍需按现场环境填写数据库连接。
5. 入库时供应商必须是系统中已有的供应商，可从下拉选择，或按回车新增后再入库。
