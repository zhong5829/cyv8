# QP12 更新说明（v0.0.97）

本次更新集中修复散件入库后「总进价」显示为 0 的问题，并补齐两条会把它写成 0 的操作路径。

## 一、问题修复

### 散件入库总进价显示为 0
- 在入库明细表格中直接修改「进价（不含税）」后，系统会同步更新「含税价」，不再只改一半。
- 打开入库行编辑窗口时，若该配件当前没有可用的含税价，会自动带出与「进价（不含税）」相同的金额；直接回车确认不会再写入 0。
- 修复后，明细生效时「总进价」会按「进价 × 数量」正确累计，不再整列为 0。
- 原本已有真实含税价的记录不会被覆盖，仍保持原值。

## 二、使用注意事项

1. 本次不会自动回填历史单据中已经存成 0 的含税价或总进价；如需处理存量数据，请先与实施人员确认后再操作。
2. 进价与含税价仍沿用既有口径：两者按同一金额同步，不按税率换算。如现场需要按税率换算，请先确认后再调整。
3. 升级安装不会覆盖已有的数据库连接与打印配置；已配置好的现场可直接升级。
4. 建议升级后先做一张散件入库单验证：分别用「表格内直接改价」和「行编辑窗口」两种方式录入，确认生效后总进价与预期一致。
