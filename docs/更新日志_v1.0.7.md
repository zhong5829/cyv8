# QP12 更新说明（v1.0.7）

本次更新修复两个重要问题：散件入库表格导入后明细顺序错乱，以及销售退货后库存中出现"重复配件"批次行的问题。程序版本号升级为 1.0.7。

## 一、散件入库 · 表格导入顺序修复

1. **导入后明细区顺序与表格一致**：修复表格导入后明细区行顺序与表格不一致的问题。现保证导入后明细区第一行对应表格第一行、第二行对应表格第二行（例如表格第一行 C-1546、第二行 C-1733，导入后明细区即为 C-1546、C-1733）。
2. 勾选「合并同编号」时，重复配件数量仍累加到该编号首次出现的那一行，位置同样遵循表格顺序，行为不变。

## 二、销售退货 · 库存"重复配件"问题修复

1. **退货不再产生重复批次行**：修复销售退货时因库存成本价（加权平均）在销售后发生变动，导致退货匹配不到原批次、每次都新增一行重复配件批次的问题。现退货会自动找到原批次并回补库存，不再产生多余的批次行。
2. 退货的入库成本、金额回补全部落在原批次上，库存汇总数量、金额保持准确。

## 三、使用注意事项

1. 桌面端升级不会覆盖已有的数据库连接与打印配置。
2. 若升级前因该问题已产生过重复的批次行（表现为库存查询中同一配件多出一行日期异常的记录），升级后不会再新增，历史残留请联系实施人员核实处理。
