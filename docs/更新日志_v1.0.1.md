# QP12 更新说明（v1.0.1）

本次更新集中修复「订单生成·选择配件」窗口的多个操作问题，并修复 Web 端查单默认日期在早间退一天的问题。程序版本号升级为 1.0.1。

## 一、选择配件窗口修复与优化

1. **确认订货后不再自动无限下滑**：修复确认订货后配件列表自动向下无限加载、直到拉完全表的问题（原因为列表重建后键盘焦点悬空，触发反复"滚到底自动加载"）。
2. **确认订货后保持原位与选中**：订货确认后窗口停留在所选配件行并保持选中，已订列即时变绿；不再跳回列表前部。订多少个配件都可以连续选件。
3. **订货录入窗就地弹出**：双击配件弹出的订货录入窗口直接显示在选择配件窗口中央，不再弹到主窗口位置。
4. **拖住滚动条贴底不再无限加载**：手动拖动滚动条停在底部时，列表不会反复自动加载；继续滚动仍正常翻页。
5. **打开历史计划单自动定位**：打开历史计划单的选择配件窗口时，自动定位到最后一次已订的配件行并蓝色选中，进货/销售历史随之联动显示。
6. **订货行项号修复**：订货明细的项号此前恒为 0，现按单内顺序编号（1、2、3……），与旧系统口径一致。

## 二、Web 端修复

1. **查单默认日期修复**：单据查询页的默认起止日期此前在早上 8 点前会显示成前一天（如 17 号早上打开默认 16 号），现按本地时间取当天日期。整单确认的出库日期同步修复。

## 三、使用注意事项

1. 项号修复仅对本次升级后新订的行生效；此前订的行项号已存为 0，如需将存量历史行的项号重新编号，请联系实施人员另行处理。
2. 桌面端升级不会覆盖已有的数据库连接与打印配置。
3. 手机浏览器如仍显示旧样式，请刷新页面（或清除浏览器缓存）后再使用。
